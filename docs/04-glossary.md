# 04. 용어집

| 용어 | 뜻 |
|---|---|
| 그라운딩 (Grounding with Google Search) | Gemini가 Google 검색 결과를 읽고 출처와 함께 답을 만드는 기능 |
| 그라운딩 결과 (Grounded Result) | 그라운딩으로 만든 답변. 수정·분석·저장 금지 ([06](06-search-policy.md)) |
| 검색 제안 (Search Suggestions) | 그라운딩 응답에 오는 Google 검색 칩 HTML. 결과와 함께 반드시 표시 |
| 검색 창 | 그라운딩 결과를 에이전트 답변과 분리해 보여주는 UI 영역 |
| 사용자 확인 가격 | 사용자가 판매처에서 직접 보고 입력한 가격 (`user_verified`) |
| 순절감액 | 위약금·전환 비용 등을 뺀 실제 절감액 |
| needs_check | 근거가 부족해 계산을 보류한 상태. 에이전트는 숫자를 말하지 않음 |
| 리포트 | 결정·완료 기록 (`docs/reports/`) |
