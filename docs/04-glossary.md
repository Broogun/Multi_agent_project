# 04. 용어집

| 용어 | 뜻 |
|---|---|
| 검색 결과 | 검색 제공자가 반환하는 답변과 출처. 수정·분석·저장 금지 ([06](06-search-policy.md)) |
| 검색 제안 (Search Suggestions) | 제공자가 보내는 검색 제안. `suggestions_html` 로 전달하며 없으면 `null` |
| 검색 창 | 검색 결과를 에이전트 답변과 분리해 보여주는 UI 영역 |
| 사용자 확인 가격 | 사용자가 판매처에서 직접 보고 입력한 가격 (`user_verified`) |
| 순절감액 | 위약금·전환 비용 등을 뺀 실제 절감액 |
| needs_check | 근거가 부족해 계산을 보류한 상태. 에이전트는 숫자를 말하지 않음 |
| 리포트 | 결정·완료 기록 (`docs/reports/`) |
