# 03. 제품 계획

기준 기획: [통합 문서](https://docs.google.com/document/d/1qNxeOV329Fr0PMaX9TIPHjwHkG9RrHqN3F6OLKTHtNU/edit). 여기에는 저장소 기준의 범위와 일정만 둔다.

## 한 줄 정의
사용자의 재무 목표와 소비 맥락을 바탕으로, 구매 전 판단과 절약 대안 탐색을 돕는 에이전트. 탐색은 검색, 판단에 쓰는 숫자는 사용자가 확인한 값과 계산 코드. 검색·LLM 제공자는 미정이며 실제 연동은 보류한다.

## 검색 기반 흐름 (초안)
1. 사용자가 사고 싶은 것·고민을 말한다.
2. 에이전트가 필요성과 목표 영향을 먼저 묻는다 (필요 없으면 구매 보류 제안).
3. 꼭 살 물건이면 검색 창을 띄운다 → 사용자가 판매처에서 가격 확인.
4. 사용자가 확인한 가격으로 단위가격·소진 기간·목표 영향을 계산한다.
5. 결정은 사용자가 하고, 결과를 기록해 다음 판단에 쓴다.
