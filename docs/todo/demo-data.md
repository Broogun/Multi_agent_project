## 목표
페르소나 5명의 거래가 **통합 거래내역 CSV**로 생성된다. 입력 경로 B(자산관리 앱 내보내기 업로드)를 가정하므로 카드·계좌·간편결제 통합 코드는 만들지 않는다. 온보딩(3개월 일괄)과 운영(일별 새 거래 + 유저 기록) 흐름을 재현할 수 있다. 페르소나마다 얽힌 문제, 숨은 사실(추가 질의의 정답), 평가 케이스가 있다. `uv run pytest`로 재현성과 정합성을 확인한다.

## 페르소나: 얽힌 문제 묶음 + 함정
한 사람에게 문제 하나가 아니라, 서로 얽힌 문제 여러 개(크기·제약·순서가 다름)와 함정(하면 안 되는 것)을 넣는다. 월 여유(수입 − 지출)는 목표 부족분보다 작게 맞춘다. 여유가 크면 "저축을 늘리면 된다"로 끝나서 복합 문제가 되지 않는다. 각 페르소나의 스토리는 `tests/test_demo_data.py`의 페르소나별 테스트로 고정한다.

| ID | 프로필 | 난이도 | 얽힌 문제 | 함정 | 상태 |
|---|---|---|---|---|---|
| P1 | 27세 여, 직장인, 오피스텔 월세 | Lv1 | 적금이 필요액보다 조금 모자람. 구독 중복·가격 인상·무료체험 전환(작음)만으로는 부족 → 주말 배달 조정을 함께 | 가족결합 통신비 대표 결제 + 정산 입금, 신용카드 대금 | 초안 완료 |
| P2 | 21세 남, 대학생, 본가 | Lv2 | 카페 증가(공부 장소와 섞임) → 집커피는 구매비용 비교로 이어짐. 편의점·게임. 여유를 먼저 떼어 두고 모자란 만큼 지출로 | 시험기간 급증을 추세로 보기, 이름 없는 용돈·알바 입금 | 초안 완료 |
| P3 | 29세 여, 직장인, 장거리 출퇴근 | Lv2 | 적금 부족. 가장 큰 택시는 줄이기보다 경비 청구, 약정 끝난 휴대폰 요금제, 야근 배달 | PT(보호, 3개월 할부), 연간 결제 첫 등장, 신용카드 대금, 생활비·축의금 출금 | 초안 완료 |
| P4 | 24세 여, 대학생, 자취·알바 | Lv3 | 목표 부족 = 수입 감소(가장 큼) + 배달·편의점·못 받은 정산(각각 작음) + 목표 조정 여지 | 더치페이, 이름 없는 이체, 앱 오분류, 현금 | 초안 완료 |
| P5 | 26세 남, 입사 4개월 | Lv3 | 월급 직후 쇼핑·배달은 전부 끊어야 겨우 필요액에 닿음 → 월급날 먼저 떼어 두기 + 목표 시점 조정. 해지했다던 구독 | 잦은 반품, 노트북 12개월 할부, 신용카드 대금, 월세·부모님 용돈 출금 | 초안 완료 |
