# Swarm 비용 줄이기: P1 재실행 비교

- 날짜: 261127
- 작성: A (Broogun)
- 관련: [Swarm 코어 리포트](261127-1530-a-swarm-core.md), 코드 `src/spending_agent/agent/swarm.py`, `agent/memory.py`

## 결론
- P1(gpt-6.1-terra, 12/1~1/31) 입력 토큰 **3,381,000 → 1,335,547 (−61%)**, 강제 마무리 3번 → 0번.
- 이미 수락한 제안 재제안 0개 (전: 수락 10개 중 4개 중복). 첫 제안이 12/20 → 12/13.
- 쟁점 재현율 0.95 → 0.925로 비슷. 처음 두 주 제안 0개는 남은 문제.

## 원인과 수정
| 원인 (수정 전 실측) | 수정 |
|---|---|
| calculate 199번, 식 하나에 LLM 스텝 하나 | `calculate_many`: 식 최대 10개 한 번에. 식마다 calculate 로그를 남겨 숫자 근거 규칙 유지 |
| 반복결제 26번·목표 50번 재조회 | 피드백 안 조회 캐시 (전처리 포함). 같은 역할 재호출은 짧은 안내만. 질문·계산은 캐시 안 함 |
| 호출당 입력 7천 → 1.7만 토큰 증가 | 메모리 상한 (쟁점 7·질문답 5·반응 8·패턴 6·다음 질문 3), 역할별 메모리·작업판 |
| 반려 핑퐁, 거래 조회 limit 100 | 리뷰 통과 기준 명확화, 반려 한도 시 검산된 제안은 남은 부족분과 함께 전달, 거래 조회 기본 20·최대 30건·열 5개, 도구 결과 6천 자 |
| 같은 피드백 안 중복 제안 | 같은 대상·행동은 작업판에 한 번만 |
