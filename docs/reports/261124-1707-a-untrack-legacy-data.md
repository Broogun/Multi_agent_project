# 기본 구조에서 사용하지 않는 수동 데이터 추적 해제

- 날짜: 261124
- 작성: A (Codex와 작업)
- 관련: [데이터 안내](../../data/README.md), [기본 구조 정리](261124-1655-a-base-structure.md)

## 결론
현재 코드에서 사용하지 않는 `data/manual/` YAML을 Git 추적에서 제외한다. 기본 구조에는 `data/README.md`만 포함하고 로컬 데이터 원본은 유지한다.

## 배경
사용자가 기존 데이터 업로드 여부를 확인하며 수동 YAML도 기본 구조에 필요한지 물었다. 현재 코드에는 해당 파일을 읽는 구현이 없다.

## 한 일 / 결정
- `benefit_rules.yaml`, `merchants.yaml`, `subscriptions.yaml`의 추적을 해제하고 `.gitignore`의 수동 데이터 예외를 제거한다.
- 프로젝트에서 직접 선언한 `pyyaml` 의존성을 제거하고 잠금 파일을 동기화한다. 다른 라이브러리가 요구하는 간접 의존성은 유지한다.
- README와 폴더 구조, 데이터 안내를 실제 공유 범위에 맞춘다.
- 과거 리포트는 당시 기록으로 유지하며 이전 버전은 기존 보존 태그에서 확인할 수 있다.

## 버린 대안
- 로컬 YAML까지 삭제: Git 공유에서 제외하는 것으로 충분하므로 원본을 남긴다.
- 기본 구조에 수동 데이터를 계속 포함: 현재 사용처가 없으므로 제외한다. 필요해지면 담당 작업에서 검토한 데이터를 추가한다.

## 근거
- 코드와 테스트에서 수동 YAML을 읽거나 `yaml`을 import하는 부분이 없다.
- `uv sync --group dev`, `uv run ruff check .`, `uv run pytest` 통과. 테스트 결과는 13 passed.
- Git 인덱스에서 데이터 안내 문서만 추적하며 기존 YAML은 로컬에 존재하고 ignore 규칙에 해당함을 확인했다.
