## 버린 대안
- 다른 외부 제공자로 즉시 교체: 제공자가 정해지지 않아 새 의존성이나 키를 추가하지 않는다.
- 검색 계약과 가짜 구현까지 삭제: 화면·계산·에이전트의 독립 개발에 필요하므로 유지한다.

## 근거
- 실제 검색·에이전트 구현은 아직 없고 패키지 자리와 가짜 구현만 있다.
- `uv sync --group dev`: 제거한 SDK와 종속 패키지 정리 및 잠금 파일 동기화 완료.
- `uv run ruff check .`: 통과. `uv run pytest`: 13 passed. `git diff --check`: 통과.
- README의 문서 링크와 기본 패키지 import도 하네스 테스트로 확인했다. 실제 외부 API는 호출하지 않았다.
