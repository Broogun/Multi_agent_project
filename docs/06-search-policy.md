# 06. 검색 사용 원칙

검색 기능을 만들거나 고치는 사람·에이전트는 이 문서를 지킨다. 아래 내용은 프로젝트의 데이터 처리 원칙이며 특정 제공자의 약관 해석이 아니다.

## 현재 상태

검색 제공자는 **OpenAI GPT 웹 검색**으로 정했다 (261127, 비교 테스트에서 링크 표시와 출처 품질이 Gemini 보다 나았다). 실제 연동 전까지 화면과 연동은 `fakes.fake_search_panel` 및 기존 `SearchPanelEvent` 계약으로 개발한다. 구현 전과 발표 전에 OpenAI 공식 약관·표시 규칙·가격을 확인하고 검토 결과를 리포트로 남긴다 (아래 '미확인').

## 반드시 지킬 것

| 규칙 | 프로젝트 원칙 | 구현 |
|---|---|---|
| 검색 결과를 **별도 검색 창**에 표시한다 | 에이전트 답변과 구분 | 검색 창 카드로만 보낸다 (`suggestions_html` 은 쓰지 않는다) |
| 결과 **문장을 고쳐 쓰지 않고**, 에이전트 답변 등 다른 내용을 **끼워 넣지 않는다** | 출처 문장 그대로 표시 | 요약·제목·인용을 LLM 으로 다시 쓰지 않는다. 아래 '표시 전 필터'만 허용 |
| 결과를 **에이전트 대화·state·DB에 넣지 않는다** | 저장·분석·학습 입력 금지 | 검색 결과는 UI 이벤트로만. 테스트로 확인 |
| 링크로 **크롤링·색인·DB를 만들지 않는다**. 링크된 페이지를 코드나 에이전트가 열지 않는다 | 사용자 직접 확인 | 링크는 사용자가 누르는 용도로만 |
| 링크에 **중간 페이지·리다이렉트·클릭 추적**을 추가하지 않는다 | 원래 링크 유지 | 추적 파라미터(`utm_*` 등)는 지우고 원래 주소로 바로 연다 |
| **검색어에 개인정보·재무 정보를 넣지 않는다** | 상품명·용량만 전달 | 검색어 제한과 개인정보 필터 검증 |

## 표시 전 필터 (규칙 코드, LLM 없음)

검색 결과는 보여 주기만 하므로, 띄우기 전에 쓸 만한 것을 앞에 둔다. 처리는 표시하는 순간에만 하고 저장하지 않는다.

| 필터 | 규칙 |
|---|---|
| 링크 정리 | 추적 파라미터 제거, 같은 주소 하나로 |
| 출처 등급 | 도메인 목록으로 `공식`(공공기관·통신사·공식몰) / `비교` / `블로그·커뮤니티` 표시. 공식을 앞에 |
| 기준일 | 게시일이 오래됐거나 "종료·마감" 표현이 있으면 `확인 필요` 표시 |
| 중복 제거 | 같은 도메인·같은 제목은 하나만 |
| 관련도 | 검색한 스펙과 맞지 않는 결과는 뒤로 |
| 숨김 표시 | 뒤로 보내거나 접은 결과는 지우지 않고 "N건 더 보기"로 보여 준다 (사용자가 직접 확인 가능) |

필터는 순서·표시만 바꾼다. 결과 내용으로 에이전트 판단·계산·저장을 하지 않는다.

## 가격과 계산

- 검색 결과에 보이는 가격으로 절감액을 계산하지 않는다. LLM이 만든 숫자이고, 오래되었거나 틀릴 수 있다.
- GPT 검색 요청에는 구체 가격을 단정하지 않고 판매처 확인을 안내하도록 지시한다.
- 계산에 쓰는 가격의 출처 유형: `user_verified`(사용자 확인), `receipt_ocr`, `capture_ocr`, `public_api`. 검색 결과는 입력 경로가 없다.
- 사용자가 확인한 가격은 그 사용자 본인의 비교에만 쓴다. 여러 사용자 가격 공유는 향후 확장 (비식별화·동의·검증 필요).
- 검색 창 고지 문구: "검색 결과이며, 실제 가격은 판매처에서 확인하세요."

## 비용

GPT 웹 검색의 과금 방식·금액은 미확인이다. 도입 전에 공식 가격과 호출 제한을 확인하고 예산을 정한다. 현재 가짜 구현과 테스트는 외부 검색 API를 호출하지 않는다.
