# 06. 검색 사용 원칙

검색 기능을 만들거나 고치는 사람·에이전트는 이 문서를 지킨다. 약관 해석은 2026-11-24에 원문을 읽고 정리한 것이며 법률 자문이 아니다. 약관은 바뀌므로 구현 전과 발표 전에 원문을 다시 확인한다.

## 사용하는 검색: Gemini API Google 검색 그라운딩

출처: [Gemini API 추가 이용약관](https://aistudio.google.com/docs/terms) (2026-03-23 시행), [Grounding with Google Search](https://aistudio.google.com/docs/google-search), [가격](https://aistudio.google.com/docs/pricing)

## 반드시 지킬 것

| 규칙 | 약관·원칙 근거 | 구현 |
|---|---|---|
| 그라운딩 결과를 **별도 검색 창**에 표시하고, Google 검색 제안(`search_entry_point.rendered_content`)을 함께 렌더링한다 | 약관: 결과는 검색 제안과 함께 질문한 사용자에게만 표시 | 검색 창 컴포넌트가 둘 다 받는다 |
| 결과를 **수정하지 않고**, 에이전트 답변 등 다른 내용을 **끼워 넣지 않는다** | 약관: modify, intersperse 금지 | 답변 텍스트·링크·제목을 손대지 않는다 |
| 결과를 **에이전트 대화·state·DB에 넣지 않는다** | 약관: cache, analyze, learn from 금지 | 검색 결과는 UI 스트림으로만. 테스트로 확인 |
| 링크로 **크롤링·색인·DB를 만들지 않는다**. 링크된 페이지를 코드가 열지 않는다 | 약관 + 우리 원칙 | 링크는 사용자가 누르는 용도로만 |
| 링크에 **중간 페이지·리다이렉트·클릭 추적**을 두지 않는다 | 약관: interstitial, redirect, click tracking 금지 | 링크는 원래 URL로 바로 연다. 화면 전체 상호작용 지표만 수집 |
| 사용자 대화 기록에 결과 텍스트를 두는 것은 **최대 2년** | 약관 예외 | 대화 기록 보관 기간 2년 이하 |
| 결과를 다듬으려고 Gemini에 다시 보내는 것은 허용. 표시하지 않은 중간 결과는 지운다 | 약관 예외 | 다듬기 호출은 검색 모듈 안에서만 |
| **검색어에 개인정보·재무 정보를 넣지 않는다** (상품명·용량만) | 우리 원칙 | 검색어 길이 제한, 숫자·이름 필터 |
| **결제 계정이 연결된 키**를 쓴다 | 무료 티어 입력은 Google 학습·사람 검토에 쓰임 | `.env`의 `GEMINI_API_KEY` |
| 만 18세 이상 서비스로 운영한다 | 약관: 18세 미만 대상 앱 금지 | 가입 시 연령 확인 |

## 가격과 계산

- 검색 결과에 보이는 가격으로 절감액을 계산하지 않는다. LLM이 만든 숫자이고, 오래되었거나 틀릴 수 있다.
- 프롬프트로 "구체 가격을 단정하지 말고 판매처 확인을 안내하라"고 요청한다 (요청 설계는 수정이 아니다).
- 계산에 쓰는 가격의 출처 유형: `user_verified`(사용자 확인), `receipt_ocr`, `capture_ocr`, `public_api`. 검색 결과는 입력 경로가 없다.
- 사용자가 확인한 가격은 그 사용자 본인의 비교에만 쓴다. 여러 사용자 가격 공유는 향후 확장 (비식별화·동의·검증 필요).
- 검색 창 고지 문구: "검색 결과이며, 실제 가격은 판매처에서 확인하세요."

## 비용

- Gemini 3 이후 모델: 월 5,000회 검색 무료, 이후 1,000회당 $14, 하루 1,500회 상한 (2026-11-24 가격 페이지 기준). 질문 하나에 검색이 여러 번 일어날 수 있고 검색마다 과금된다.
- Gemini 2.5 이하 모델은 프롬프트 단위 과금 (요약본 기준, 원문 재확인 필요).

- [ ] 링크가 Google 리다이렉트 URL로 올 때 처리
